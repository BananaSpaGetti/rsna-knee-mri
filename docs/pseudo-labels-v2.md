# Pseudo labels v2 — three image teachers (v6c, v4b, convnexts)

Round-10 rerun of the pseudo_v1 recipe with the ConvNeXt-Small arm added as a third teacher. The final-variant column is still named `pseudo_v1` by the script; here it is `pseudo_v2.csv`. Result: label-set gold-58 macro 0.9174 vs 0.9174 for pseudo_v1 and 0.8949 for consensus alone; the teacher ensemble itself scores 0.8915 vs 0.894 with two teachers - a third teacher of the same strength does not move the label set.

Generated by `src/pseudo_labels.py` from `consensus_v1.csv` and 3 image teachers (weights-v6c, weights-v4b, working-convnext), MIX_W = 0.5, SILENT_RATIO_MIN = 0.3. Train rows with a teacher: 4349; gold-58 rows kept as consensus.
